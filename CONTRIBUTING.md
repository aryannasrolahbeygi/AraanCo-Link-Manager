# Contributing

Thank you for improving AraanCo Link Manager!

1. Open an issue before substantial feature work, to discuss scope.
2. Keep the extension lightweight and local-first; avoid requiring an external server or unnecessary permissions.
3. Support both **English** and **Persian** in user-facing strings.
4. Run tests with Node.js 20+: `node --test tests/*.test.mjs`.
5. Do not commit private links, credentials, Google account data, signing keys, or personal exports.
6. Submit a focused pull request with a description and test results.

For bugs, include Chrome version, extension version, reproduction steps, and *redacted* screenshots or logs.
